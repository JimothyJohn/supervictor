Pipeline

./Quickstart orchestrates build, test, deploy, and device management through progressive stages.

CommandWhat it does
./Quickstart Start to finish: toolchain, .env, certs, build, tests, local mTLS endpoint, then a simulated machine or a board
./Quickstart status | down What the local endpoint and simulator are doing; stop them
./Quickstart -t lint → build → unit → integration (staging smoke)
./Quickstart edge Build + flash the ESP32-POE-ISO firmware via espflash
./Quickstart deploy Deploy the self-hosted staging box (scripts/deploy-staging.sh)
./scripts/ship.sh Release what is on master to the prod box, resumably (plan; go to run)
./Quickstart certs ca Initialize the root CA for mTLS
./Quickstart certs device <name> Issue a device client certificate
./Quickstart certs server <name> Issue a server/TLS certificate
./Quickstart certs verify Verify the mTLS certificate chain
./Quickstart certs handshake Simulate mTLS handshake against a running server
./Quickstart ping mTLS GET to verify the server is reachable
./Quickstart fleet Fleet health table over admin mTLS
./Quickstart onboard End-to-end device onboarding (certs + flash + verify)

TRACE=1 traces any command; ENV selects .env.<stage>.

Testing Tiers

Unit

The whole workspace on the host: in-memory SQLite, in-process mTLS, no infra required.

./Quickstart unit

Local mTLS

The endpoint on this machine terminating mTLS itself, with a simulated machine posting to it.

./Quickstart up --sim

Staging smoke

HTTPS + client certs against the deployed staging box.

./Quickstart integration

Environments

Dev

Local endpoint from ./Quickstart, terminating mTLS in-process

Staging

staging.supervictor.advin.io: one EC2 box, systemd unit, SQLite; carries the simulated fleet

Production

supervictor.advin.io: a second box from the same template, Let's Encrypt server cert, strict registration

Certificate Management

The ./Quickstart certs subcommand manages the full mTLS certificate lifecycle. 

./Quickstart certs ca                          # Create root CA
./Quickstart certs device esp32                # Issue device cert
./Quickstart certs server <host>               # Issue server cert
./Quickstart certs verify                      # Verify cert chain
./Quickstart certs handshake                   # Simulate mTLS handshake

Quick Start

Clone the repository

git clone git@github.com:JimothyJohn/supervictor.git
cd supervictor

Run the guided path: toolchain check, .env, fleet CA and certificates, build, tests, a local mTLS endpoint on https://localhost:8443, then a simulated machine or a board over USB. Idempotent; prompts only where ambiguous. make help lists the same stages as make targets.

./Quickstart

Put a board on a reachable endpoint (certificate, registration, flash, first handshake)

./Quickstart onboard <device> <owner> <host>

Install the endpoint on a Linux box as one static binary (when ready)

make deploy    # or scripts/install-endpoint.sh on the target

Infrastructure

One static binary, a systemd unit, three PEMs and a SQLite file on any Linux box (scripts/install-endpoint.sh, endpoint/deploy/). The reference box is one EC2 instance from endpoint/template-staging.yaml; nothing in the service depends on AWS.
